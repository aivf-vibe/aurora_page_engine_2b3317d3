Getting Started

Get up and running with Aurora Platform in just a few simple steps.

1

Create an Account

Sign up for a free Aurora Platform account to get started. No credit card required.

Sign Up Now →
2

Install CLI

Install our command-line interface to manage your projects from your terminal.

npm install -g @aurora/cli
3

Initialize Project

Create your first project using our interactive setup wizard.

aurora init my-awesome-app
4

Deploy to Production

Deploy your application with a single command and see it live in minutes.

aurora deploy --prod

Frequently Asked Questions

What programming languages are supported?

We support Node.js, Python, Ruby, Go, Java, and .NET. You can also deploy Docker containers for any other language or framework.

How does pricing work?

We offer a generous free tier for development and small projects. Paid plans start at $5/month and scale based on usage. You only pay for what you use.

Can I use my own domain?

Yes! You can easily connect your custom domain with our built-in SSL certificate management. We support both root domains and subdomains.

Is there a limit on requests or bandwidth?

Free tier includes 100GB bandwidth and 100k requests per month. Paid plans offer unlimited bandwidth and requests with fair usage policies.
